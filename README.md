# 경영통계 대시보드

요양병원의 **월별 경영 통계표(엑셀)를 올리면** 자동 요약, 그래프, 상세 통계표를 보여주고,
**엑셀 · 인쇄용(PDF) 보고서**로 내보내는 프로그램입니다.

- 영남이공대학교 캡스톤 디자인 프로젝트 (병원 현장 문제 연계)
- 과제: "통계 보고서를 매달 손으로 작성하고 있어서 자동화하고 싶다"
- **병원 PC에 설치해서 쓰는 프로그램**입니다. 데이터는 PC 밖으로 나가지 않습니다.

> ⚠ 이 저장소에는 병원 데이터(엑셀)가 들어 있지 않습니다. 개발에는 병원 양식으로 만든 **가상 데이터**만 썼습니다.

---

## 1. 화면 구성

| 위치 | 내용 |
|---|---|
| **왼쪽 사이드바** | 엑셀 올리기 · 기준월 · 조회기간(3/6/12개월) · 적정선/경고 기준 · 보고서 내보내기 |
| **개요** 탭 | 맨 위 **자동 요약** 문장 + **확인 필요 항목** → 핵심 지표 카드 6개(전월·전년 대비, 13개월 추이) → ⭐ 즐겨찾기 지표 |
| **환자·병상** 탭 | 월말 재원환자(보험별), 병상가동율(적정선 점선), 입원·퇴원, 환자군(A1~A7), 상세 표 |
| **수익** 탭 | 총진료비 추이, 보험별 비중, 입원·외래 청구, 인당 진료비, 재활치료(코드별), 한의사별(가명), 산소·기타 행위, 상세 표 |
| **비용** 탭 | 주요 비용 추이·구성, 인건비, 관리비, 식자재·식단가, 간병·위생소모품 손익, 의약품, 상세 표 |
| **사용자 정의 통계** 탭 | 통계표의 **모든 항목** 중 원하는 것을 골라 비교 · 즐겨찾기 등록 |

### 자동으로 알려주는 것 ("확인 필요 항목")
- 🔴 **적정선 미달**: 병상가동율이 적정선(기본 95%)보다 낮을 때
- 🔴/🟡 **증가·감소**: 총진료비, 청구금액, 인건비 등이 직전 12개월 평균보다 ±10% 이상 변했을 때
- 🔴/🟡 **재활 코드 급변**: 재활치료 수가코드가 전월 대비 ±30% 이상 변했을 때 (500만 원 이상 항목)
- 🟡 **미입력 의심**: 0이 나올 수 없는 항목(인건비, 총진료비 등)이 0일 때
  → 값은 지우지 않고 표시만 하며, 그래프에서는 빈칸으로 둡니다.

## 2. 설치 (처음 한 번만)

1. **Python 3.12**를 설치합니다. (설치 화면에서 "Add python.exe to PATH" 체크)
2. 이 폴더에서 PowerShell을 열고 아래 두 줄을 입력합니다.

```
py -3.12 -m venv .venv
.venv\Scripts\python -m pip install -r requirements.txt
```

- 첫 줄: 이 프로그램 전용 파이썬 공간(`.venv` 폴더)을 만듭니다.
- 둘째 줄: 필요한 패키지를 **정해진 버전 그대로** 설치합니다.

## 3. 사용 방법

1. **`실행.bat`을 더블클릭** → 브라우저에 http://localhost:8501 이 열립니다. (끄려면 까만 창을 닫기)
2. 왼쪽에서 **월별 통계표 엑셀을 올립니다.** (`Sample data` 시트가 있는 파일)
   - `data` 폴더에 넣어 둔 파일은 목록에서 바로 고를 수 있습니다.
3. **기준월**과 **조회기간**(3·6·12개월)을 고릅니다. 그래프와 표가 그 기간으로 바뀝니다.
4. 필요하면 **환경설정**에서 병상가동율 적정선, 확인 필요 기준(±%)을 바꿉니다. (다음에 켜도 유지)
5. **보고서 내보내기**
   - 📥 **엑셀 보고서**: 요약 · 핵심지표 · 환자_병상 · 수익 · 비용 시트 (원래 숫자 그대로)
   - 🖨 **인쇄용 보고서**: 받은 파일을 열고 [인쇄] → 대상 **'PDF로 저장'** 을 고르면 PDF가 됩니다.
   - 각 표 아래 **⬇ 엑셀로 받기**, 그래프 오른쪽 위 📷 아이콘으로 **이미지(PNG)** 저장
6. **자주 보는 항목 고정하기**: `사용자 정의 통계` 탭에서 항목을 고르고 **⭐ 즐겨찾기에 추가**
   → `개요` 탭 아래에 당월·전월·전년 비교 표로 나옵니다.

### 표 기능
첫 열(항목 이름) 고정 · 열 머리글을 눌러 정렬 · 표 오른쪽 위 돋보기로 검색

## 4. 보안 (중요)

- 이 프로그램은 **이 PC에서만** 접속되도록 설정되어 있습니다. (`.streamlit/config.toml` — 지우지 마세요)
- 사용 통계를 외부로 보내지 않고, 글꼴 등도 인터넷에서 불러오지 않습니다.
- **병원 엑셀을 생성형 AI(ChatGPT, Claude 등)에 올리지 마세요.** 비식별 데이터라도 마찬가지입니다. (병원 요청)
- 한의사 이름처럼 개인을 알 수 있는 값은 **읽는 즉시 가명**(한의사_1, 한의사_2 …)으로 바꿉니다.
- 병원 데이터는 Streamlit Cloud 같은 외부 서버나 GitHub에 올리지 않습니다. (`.gitignore`가 엑셀을 막습니다)
- 실제 병원 데이터를 다룰 때는 **OneDrive 같은 클라우드 동기화 폴더 밖**(예: `C:\경영통계`)에서 실행하세요.

### 실제 병원 데이터로 처음 시험할 때
1. 병원 PC에서 실제 월별 통계표 엑셀을 올립니다. (시트 이름이 `Sample data`가 아니어도 **1행에 월별 날짜가 있는 시트를 자동으로** 찾습니다)
2. 사이드바 **🔍 데이터 점검**을 봅니다.
   - `✅ 모든 항목 찾음` → 그대로 사용하면 됩니다.
   - `⚠` 표시 → 못 찾은 항목 목록이 나옵니다. **이 목록 화면만 캡처해서 개발자에게 보내면**
     `config.py`의 이름을 맞춰 줄 수 있습니다. (데이터 값은 보낼 필요 없음)
3. 항목이 몇 개 없어도 프로그램은 멈추지 않고, 그 그래프 칸에만 "⚠ … 건너뜁니다"가 표시됩니다.
4. "숫자가 하나도 읽히지 않았습니다"가 나오면 엑셀에서 파일을 열어 **저장**한 뒤 다시 올립니다.

## 5. 설정 바꾸기 (코드를 몰라도 되는 부분)

`config.py`의 목록만 고치면 화면이 바뀝니다. 항목 이름은 엑셀에 적힌 이름 그대로(공백·줄바꿈 제외) 씁니다.

| 설정 | 하는 일 |
|---|---|
| `KPIS` | 개요 탭 핵심 지표 카드 6개 |
| `COST_ITEMS` | 비용 탭 '주요 비용' 묶음 |
| `PATIENT_DETAIL`, `REVENUE_DETAIL` | 탭 아래 상세 통계표 · 보고서에 들어갈 줄 |
| `ALERT_ITEMS` | '확인 필요 항목'에서 검사할 항목 |
| `NEVER_ZERO` | 0이면 '미입력 의심'으로 볼 항목 (진짜 0일 수 있는 항목은 넣지 마세요) |
| `SPAN_CHOICES` | 사이드바 조회기간 선택지 |
| `PSEUDONYM_SECTIONS` | 이름을 가명으로 바꿀 구역 |

예) 개요 카드에 '식자재'를 추가하려면:
```python
("식자재", ("식자재", "식자재", "합계"), "money"),
```

**새 통계가 필요할 때**: 엑셀에 새 줄(항목)을 추가하면 `사용자 정의 통계` 탭에 **코드 수정 없이 자동으로** 나타납니다.

## 6. 폴더 구조 (개발자용)

```
├─ app.py              시작 파일. 화면 조각을 "조립"만 함 (탭 순서도 여기서)
├─ config.py           설정값 모음 (위 5번)
├─ core/               계산 (streamlit 사용 금지 → 화면 없이 테스트 가능)
│  ├─ monthly.py       엑셀 읽기 · 항목 찾기 · 가명 처리
│  ├─ kpi.py           핵심 지표 · 숫자 표시 형식(억/만/명/%)
│  ├─ summary.py       자동 요약 문장 · 확인 필요 항목
│  ├─ quality.py       미입력 의심(0) 찾기
│  ├─ revenue.py       재활치료 분류 · 금액 눈금
│  ├─ cost.py          비용 묶음 · 간병/위생소모품 손익
│  ├─ custom.py        사용자 정의 통계 · 즐겨찾기
│  ├─ check.py         데이터 점검 (필요한 항목이 엑셀에 있는지)
│  ├─ settings.py      사용자 설정 저장 (user_settings.json, 이 PC에만)
│  └─ view.py          화면 전체가 함께 쓰는 '지금 보는 조건'
├─ ui/                 화면
│  ├─ theme.py         색 · CSS · 그래프/표 공통 모양
│  ├─ sidebar.py       사이드바 · 보고서 버튼
│  └─ pages/           탭 하나 = 파일 하나, 각 파일은 render() 하나
├─ reports/            엑셀 · 인쇄용 보고서 만들기 (streamlit 사용 금지)
├─ tests/              자동 테스트 (pytest)
├─ data/               가상 데이터 엑셀 (저장소에는 안 올라감)
├─ .streamlit/         Streamlit 설정 (보안 · 색)
├─ CLAUDE.md           AI 도구가 지켜야 할 규칙
├─ requirements.txt    패키지 목록 (버전 고정)
└─ 실행.bat            더블클릭 실행
```

### 개발 규칙
1. 병원 원본 엑셀은 AI 도구에 열어 보이지 않는다. (`data/`의 가상 데이터만 예외)
2. `core/`, `reports/`에서는 `streamlit`을 쓰지 않는다.
3. `eval()` / `exec()` 금지.
4. 파이썬 파일 하나는 300줄 이하.

`tests/test_rules.py`가 위 2~4번을 자동으로 검사합니다.

### 테스트 돌리기
```
.venv\Scripts\python -m pytest
```

### 새 탭 추가하기
1. `ui/pages/새탭.py`를 만들고 `render(v)` 함수 하나를 둡니다. (`v.df` 통계표, `v.month` 기준월, `v.months` 조회기간)
2. `app.py`의 `TABS` 목록에 `("새 탭 이름", 새탭)` 한 줄을 추가합니다.
