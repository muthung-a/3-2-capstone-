경영통계 대시보드 사용 설명서

매달 작성하는 월별 경영 통계표(엑셀)를 올리면 자동 요약, 그래프, 상세 표를 보여 주고 엑셀·인쇄용 보고서로 내보내는 프로그램입니다. 설치 없이 인터넷 창에서 바로 씁니다.

접속 주소 https://muthung-a.github.io/3-2-capstone-/ 대시보드 열기 →

1접속하기

  1. Chrome 또는 Edge를 열고 위 접속 주소로 들어갑니다.
  2. "경영통계 대시보드 여는 중…" 화면이 나오고 30초~1분 뒤 대시보드가 뜹니다. 두 번째부터는 더 빨리 열립니다.
  3. 자주 쓰신다면 주소를 즐겨찾기에 추가해 두세요.
개인정보 안내 · 프로그램만 인터넷에서 내려받고, 올린 엑셀은 이 PC의 인터넷 창 안에서만 계산합니다. 엑셀 내용은 어디로도 전송되지 않으며, 창을 닫으면 올린 내용도 사라집니다.

2로그인과 계정

대시보드는 로그인한 사람만 쓸 수 있습니다. 계정은 두 종류입니다.

계정할 수 있는 일
관리자대시보드 보기·보고서 받기 + 계정 추가·삭제·비밀번호 초기화·역할 변경 + 환경설정(병상가동율 적정선, 확인 필요 기준) 변경
사용자대시보드 보기·보고서 받기, 조회기간·즐겨찾기. 환경설정은 보기만 가능

처음 한 번: 관리자 계정 만들기

  1. 그 PC에서 처음 열면 🔐 처음 사용 · 관리자 계정 만들기 화면이 나옵니다.
  2. 관리자 아이디와 비밀번호(6자 이상)를 정해 입력합니다. 바로 로그인됩니다.

직원 계정 만들기 (관리자)

  1. 왼쪽 위 👥 계정 관리를 누릅니다.
  2. ➕ 계정 추가에서 아이디·비밀번호·역할(사용자/관리자)을 넣고 계정 추가를 누릅니다.
  3. 직원이 비밀번호를 잊으면 ✏️ 계정 수정·삭제에서 새 비밀번호로 초기화합니다. 역할 변경과 삭제도 여기서 합니다.

누구나 왼쪽 🔑 내 비밀번호 바꾸기로 자기 비밀번호를 바꿀 수 있습니다. 비밀번호를 5번 틀리면 30초 동안 로그인이 막힙니다.

계정은 PC(브라우저)마다 따로 저장됩니다. 여러 PC에서 쓰려면 PC마다 관리자 계정을 만들고 직원 계정을 추가해 주세요. 비밀번호는 암호화해서 그 PC에만 저장하며, 인터넷으로 보내지 않습니다.

3엑셀 올리기

  1. 왼쪽 엑셀 파일 올리기에서 Upload를 누르거나, 파일을 그 칸으로 끌어다 놓습니다.
  2. 월별 통계표 엑셀을 고릅니다. 날짜가 1행에 월별로 적힌 시트를 자동으로 찾습니다.
  3. 몇 초 뒤 오른쪽에 대시보드가 나타납니다.
.xlsx 파일만 올릴 수 있습니다. 파일이 한셀(.cell), 예전 엑셀(.xls), 구글 스프레드시트라면 다른 이름으로 저장 → 파일 형식 "Excel 통합 문서(*.xlsx)"로 바꿔서 올려 주세요. 구글 스프레드시트는 파일 → 다운로드 → Microsoft Excel(.xlsx)입니다.

올린 뒤 꼭 볼 곳: 🔍 데이터 점검

왼쪽에 🔍 데이터 점검 · 39/39 항목 찾음 ✅처럼 나오면 정상입니다. ⚠ 표시가 나오면 프로그램이 엑셀에서 찾지 못한 항목 목록이 펼쳐집니다. 이 경우에도 나머지 화면은 그대로 쓸 수 있고, 못 찾은 항목의 그래프 칸에만 안내 문구가 나옵니다.

5탭별 내용

탭보여 주는 것

🧾 비용주요 비용 추이와 구성, 인건비, 관리비, 식자재·식단가, 간병·위생소모품 손익, 의약품, 상세 표
💊 약품약품 처방 원 데이터 시트로 진료과별 처방금액, 상위 10개 약품을 자동 계산하고 엑셀 소계와 맞는지 검산
🧩 사용자 정의 통계통계표의 모든 항목 중 원하는 것을 골라 비교, 즐겨찾기 등록

증감 표시는 국내 관례를 따릅니다: ▲ 빨강 = 증가, ▼ 파랑 = 감소. 카드 오른쪽 작은 선은 최근 13개월 추이입니다.

표는 첫 열(항목 이름)이 고정되고, 열 머리글을 누르면 정렬, 표 오른쪽 위 돋보기로 검색할 수 있습니다.

6자동 요약과 확인 필요 항목

자동 요약은 기준월의 주요 숫자를 전월·전년 동월과 비교해 문장으로 정리합니다. 보고서 첫머리에 그대로 쓸 수 있습니다.

확인 필요 항목은 눈여겨볼 숫자를 자동으로 골라 줍니다.

표시뜻
적정선 미달병상가동율이 적정선(기본 95%)보다 낮음
증가 감소총진료비·청구금액·인건비 등이 직전 12개월 평균보다 ±10% 이상 변함
재활 코드 급변재활치료 수가코드 금액이 전월보다 ±30% 이상 변함 (500만 원 이상 항목)
미입력 의심0이 나올 수 없는 항목(인건비, 총진료비 등)이 0임. 값은 그대로 두고 그래프에서만 빈칸 처리

7조회 조건 바꾸기

  • 기준월 분석할 달입니다. 바꾸면 요약·카드·표가 모두 그 달 기준으로 바뀝니다.
  • 조회기간 그래프와 표에 보여 줄 기간(3·6·12개월)입니다.
  • 아래 두 가지(환경설정)는 관리자만 바꿀 수 있습니다.
  • 병상가동율 적정선(%) 그래프의 점선과 "적정선 미달" 판단 기준입니다.
  • 확인 필요 기준(±%) 12개월 평균과 얼마나 달라야 "확인 필요"로 볼지 정합니다.

바꾼 조회기간·적정선·확인 기준·즐겨찾기는 이 PC의 이 인터넷 창에 저장되어 다음에 열어도 유지됩니다. 바꾼 직후 바로 창을 닫으면 저장되지 않을 수 있으니 몇 초 뒤에 닫아 주세요. 다른 PC나 다른 브라우저에서는 따로 저장됩니다.

8보고서 내보내기

왼쪽 아래 보고서 내보내기에 버튼이 있습니다.

  • 📥 엑셀 보고서 요약·핵심지표·환자_병상·수익·비용 시트로 된 엑셀 파일을 받습니다. 숫자는 원래 값 그대로입니다.
  • 🖨 인쇄용 보고서 (PDF 저장) 받은 파일을 열고 인쇄 → 대상 "PDF로 저장"을 고르면 PDF가 됩니다.
  • 각 표 아래 ⬇ 엑셀로 받기로 그 표만 엑셀로 받을 수 있습니다.
  • 그래프 위에 마우스를 올리면 오른쪽 위에 📷 아이콘이 나옵니다. 누르면 그래프를 그림(PNG)으로 저장합니다.

9자주 보는 항목 고정

  1. 🧩 사용자 정의 통계 탭에서 보고 싶은 항목을 고릅니다.
  2. ⭐ 즐겨찾기에 추가를 누릅니다.
  3. 🏠 개요 탭 아래에 당월·전월·전년 비교 표로 나옵니다.

엑셀에 새 항목(줄)을 추가하면 이 탭에 자동으로 나타납니다. 따로 요청하지 않아도 됩니다.

10문제가 생기면

"열지 못했습니다" 또는 화면이 계속 로딩만 돼요.
인터넷 연결을 확인하고 새로고침(F5)해 주세요. 병원 방화벽이 cdn.jsdelivr.net, pypi.org를 막고 있으면 열리지 않습니다. 이 경우 전산 담당자에게 문의하시거나, PC 설치판을 요청해 주세요.
파일 고르는 창에 엑셀 파일이 안 보여요.
파일이 .xlsx가 아닌 경우입니다. 위 3. 엑셀 올리기의 안내대로 .xlsx로 저장해서 올려 주세요.
"숫자가 하나도 읽히지 않았습니다"가 나와요.
엑셀에서 파일을 한 번 열고 저장한 뒤 다시 올려 주세요. 수식 결과가 저장되지 않은 파일일 때 생깁니다.
비밀번호를 잊었어요.
관리자에게 초기화를 요청하세요. 관리자가 한 명뿐인데 그 비밀번호를 잊었다면, 브라우저 설정에서 이 사이트의 사이트 데이터 삭제를 하면 처음 상태(관리자 계정 만들기)로 돌아갑니다. 이때 그 PC의 계정과 설정이 모두 지워지니, 관리자를 두 명 이상 만들어 두는 것을 권합니다.
숫자가 실제와 달라요.
어느 탭의 어떤 항목이, 어느 달에, 엑셀 값과 얼마나 다른지 알려 주세요. 데이터 값 자체는 보내지 않으셔도 됩니다.
화면이 이상해졌어요.
새로고침(F5) 후 엑셀을 다시 올려 주세요.

11의견 보내기

써 보시고 아래 내용을 알려 주시면 반영하겠습니다. 고친 내용은 같은 주소에 자동으로 반영되므로 새로 설치할 것이 없습니다.

  • 불편한 점, 찾기 어려운 메뉴
  • 틀린 숫자 (탭·항목·달)
  • 더 보고 싶은 통계, 위로 올리고 싶은 항목
  • 🔍 데이터 점검에 ⚠가 나오면 그 목록 화면만 캡처해서 보내 주세요.
